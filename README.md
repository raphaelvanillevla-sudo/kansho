# Kanshō — anime diary (phone web app)

A Letterboxd-style anime diary. This is the iPhone / browser version of the Kanshō desktop app.

**Install on iPhone:** open the site in Safari → Share → Add to Home Screen.

Anime data comes from MyAnimeList (via the Jikan API) with AniList as a fallback. Your own data stays on
your device; if you turn on sync it is encrypted on the device (AES-GCM) and kept in a private Gist on your own GitHub account.
